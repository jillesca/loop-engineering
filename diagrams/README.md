# Diagrams

Hand-drawn style diagrams from the talk, in three formats:

- `.png`: 1920×1080, ready for slides
- `.svg`: scalable
- `.excalidraw`: open in [excalidraw.com](https://excalidraw.com) (File → Open) to edit or reuse

File names follow the slide numbers of the [Shift.Forward() 2026 session](../talks/2026-10-shift-forward/): `S03–S18` are presented slides, `H01–H15` are backup slides.

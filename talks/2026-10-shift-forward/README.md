# Loop Engineering at Shift.Forward() 2026

**Loop Engineering: The Architecture Patterns Behind Autonomous AI Agents**
Shift.Forward() · 27 Oct 2026 · Build track · Builders & Operators · 30-minute presentation
Speaker: Jesus Illescas

## Abstract

Autonomous AI agents are reshaping how software gets built, yet few engineers understand how these systems actually work under the hood. Production systems like OpenClaw, Pi, and Hermes implement loop engineering — a pattern where an agent iterates autonomously until a task is truly complete — built on three core ideas: an agentic execution loop, context engineering, and a maker/checker sub-agent structure.

This session deconstructs how these systems are architected and gives builders a practical mental model for designing their own autonomous agents, independent of domain. You'll leave with concrete patterns for structuring execution loops, managing context reliably across runs, and using sub-agents to catch mistakes before they compound.

**Takeaways**

- How to structure an agentic execution loop that runs until a task is truly done
- How context engineering keeps agents reliable across long-running tasks
